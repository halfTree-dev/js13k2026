# 低多边形独角兽精灵绘制 Demo

## 目标
在现有 Canvas 2D 工程中验证"点集 + 三角面片 + 灰度色板"的低多边形精灵渲染管线：新增 `src/sprite.ts`（`drawSprite` + `UNICORN` 常量），`main.ts` 渲染单帧独角兽立于黑色地面上。

## 已定决策
1. **单一网格方案**：单点集 + 烘焙三角索引 + 逐三角形色阶（对应用户方案步骤 1-3）。部件化/多帧动画、字符串压缩打包均留待后续任务。
2. **drawSprite 签名**：`(ctx: CanvasRenderingContext2D, sprite: Sprite, x: number, y: number, scale = 1, flipX = false)`。"canvas 句柄"取 2D context（绘制句柄）；"点集"参数为自包含的 Sprite 结构；scale/flipX 为带默认值可选参数，经 `ctx.translate/scale` 实现（等价于等比放大点偏移，且免费支持翻转/旋转扩展）。
3. **坐标系**：锚点 (0,0) 为地面接触点（躯干中心正下方）；x+ 朝前（右）；y 向上为负；整数设计坐标。设计包围盒约 x∈[-46,58]，y∈[-82,0]。
4. **配色**：6 级白灰 ramp `['#ffffff','#efefef','#dadada','#bdbdbd','#949494','#737373']`，刻意避开背景色 #cccccc（贴合黑白世界观）。
5. **防接缝**：两遍绘制——第一遍全部三角形统一填 `palette[3]`（中间调打底遮蔽 AA 发丝缝），第二遍逐三角形填各自色阶。无需边界轮廓数据。
6. **画家算法**：绘制顺序后到前为 尾→远侧腿→躯干→颈→近侧腿→鬃→头→角→耳。关节处刻意让后画部件与躯干**重叠**（相接易漏缝，重叠被后画面片遮蔽）。
7. **数据形态**：可读的扁平 `number[]` 常量，不做 base64/字符串编码（esbuild minify + zip 足够，体积优化后置）。

## 任务

### 1. 新建 `src/sprite.ts`
```ts
export interface Sprite {
    pts: number[];     // [x0,y0,x1,y1,...] 相对锚点偏移
    tris: number[];    // 每 3 个顶点索引一组
    shades: number[];  // 第 i 个三角形的色板索引
    palette: string[]; // 色阶
}
export const GRAY_PALETTE: string[] = ['#ffffff','#efefef','#dadada','#bdbdbd','#949494','#737373'];
export const UNICORN: Sprite = { /* 下方起始网格 */ };
export function drawSprite(ctx: CanvasRenderingContext2D, sprite: Sprite, x: number, y: number, scale = 1, flipX = false): void;
```
`drawSprite` 步骤：`save()` → `translate(x,y)` → `scale(flipX?-scale:scale, scale)` → 遍历 tris 以 `palette[3]` 打底逐三角形 `fill` → 再遍历以 `palette[shades[i]]` 逐三角形 `fill` → `restore()`。无描边。代码风格与 main.ts 一致（4 空格缩进、显式 `: void`）。

### 4. 验证
1. `npx tsc --noEmit` 通过（strict 模式）
2. `npm run build` 通过，zip 体积报告确认新增量可忽略（数据为重复数字，deflate 压缩率高）
3. 打开 `build/index.html` 检查：轮廓可读为独角兽；面片明暗分层（背浅腹深、远腿最深）；无漏背景色的大缝或浮空三角形；独角兽四蹄贴地面条顶线；缩放窗口后位置/尺寸仍正确
4. （可选）临时再画一个 `flipX=true` 的小比例副本验证翻转路径，确认后删除

## 风险与对策
| 风险 | 对策 |
|---|---|
| 手调网格出现缝隙/浮空三角 | 起始网格邻接已核对；关节用重叠而非相接；视觉迭代循环 |
| 相邻面片 AA 发丝缝 | 两遍绘制，中间调打底 |
| 某些色阶与背景 #cccccc 接近 | 色板已避开该值；必要时背景微调为 #d6d6d6 |
| flipX 路径 demo 中未触发 | 可选翻转副本检查（1 行代码） |
